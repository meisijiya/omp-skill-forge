# 注释规范

多行排版和方法覆盖范围是本项目约定。注释补充职责与约束，不追求字数、数量或固定比例。

## 形式

| 场景                                   | 约定                                                       |
| -------------------------------------- | ---------------------------------------------------------- |
| 业务函数、方法、构造器                 | 展开式多行 JSDoc，包括私有函数、API 对象方法和页面内部方法 |
| 类、接口、类型、枚举                   | 展开式多行 JSDoc，包括内部声明                             |
| props、类型字段、枚举成员              | 简短说明可用单行 JSDoc，多个约束时展开                     |
| 常量对象与 Vue 宏                      | 需要说明契约时展开多行；已有声明说明足够时不重复           |
| 局部变量、状态、实现原因、文件职责     | 必要时用 `//`，自解释的可省略                              |
| 匿名回调、watch、生命周期、简单 getter | 不机械补方法文档；关键时序在相关语句旁解释                 |

类和方法的 `/**`、正文、`*/` 各占一行，即使摘要只有一句。独立业务函数被 watch 或 computed 调用时，仍按函数写文档。

```typescript
/**
 * 用户列表查询条件。
 */
interface UserQuery {
  /** 不传时查询全部状态 */
  status?: number;
}

/**
 * 按当前条件查询第一页。
 */
function handleQuery(): Promise<void> {
  query.pageNum = 1;
  return loadUsers();
}
```

## 内容

- 函数写动作与对象，类型写数据含义；摘要通常一句，不叠加“统一、高效、优雅”等无具体含义的修饰。
- 签名不能表达的行为要说明：是否覆盖、是否重置分页、是否允许重试、失败保留什么、特殊返回值代表什么。
- `@param`、`@returns`、`@throws` 只补格式、单位、范围或特殊结果，不重复 TypeScript 类型，不留空标签。
- 简单 CRUD、赋值和字符串判断不附长示例；只有调用约定确实难理解时使用 `@example`。
- 名称不清楚先改名称；注释与行为同步，不将“显示入口”写成“允许访问接口”。
- 长流程、迁移与方案比较放项目 `docs`；源码保留相关约束，必要时链接文档。

```typescript
/**
 * 仅结算有效任务；重置、取消或重复回调返回 false。
 */
```

这是方法摘要片段；实际文档紧邻对应声明，不保留悬空的 JSDoc。

## 文件头与实现注释

文件头仅说明无法从文件名和声明得知的共享职责，不列实现步骤。例如：

```typescript
// 视图组件注册表，供动态路由解析和菜单页面选择共用。
```

保留并发、取消、父级回写、资源释放、事务顺序、平台差异和第三方兼容原因。不要按长度判断价值。

```typescript
// 父级回写前可能连续成功，优先合并暂存结果。
publish([...(publishedValue ?? model.value), values.toValue(info)]);
```

省略“设置 loading 为 true”之类的逐行翻译。模板和样式同样解释布局意图、第三方覆盖或兼容原因；不逐个翻译元素与属性。

教学示例允许简短标记：`// 搜索配置`、`// 表格配置`、`// 共用表单`、`<!-- 自定义单元格插槽 -->`。正文已有过程说明时不在代码里重复。

## 整理边界

删除重复摘要、过期结论、装饰分隔线和注释掉的旧实现；保留有教学价值的有效示例。

条件编译、ESLint、TypeScript 和打包优化指令会影响行为，原样保留。版权、许可证、既有署名和生成器要求的头部不作为普通说明删除；不伪造作者、日期和版本流水。

修改前核对声明与注释用途，不用全局替换把字段、字符串、工具指令一并改掉。仅整理注释时确认运行代码未变，不附带业务重构。交付说明实际范围，不能将局部注释检查称为全项目审计。

参考 [Google TypeScript JSDoc](https://google.github.io/styleguide/tsguide.html#jsdoc-general-form) 与[注释内容](https://google.github.io/styleguide/tsguide.html#make-comments-that-actually-add-information)。本项目选择展开式声明文档，不代表单行 JSDoc 在其他项目中不合法。
