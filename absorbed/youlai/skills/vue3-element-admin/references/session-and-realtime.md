# 会话与实时连接

修改前核对 `src/utils/auth.ts`、`request.ts`、`token-refresh.ts`、`src/stores/user.ts` 和对应测试。令牌格式由后端决定，前端不能依赖“登录一定返回 JWT”。

## HTTP 会话

- 认证入口、令牌保存和退出复用现有认证模块；不在页面复制请求拦截器或解析令牌实现另一套会话。
- 并发失效请求共用一次续期。重放有次数限制，登录和续期自身不进入续期循环。
- 使用会话版本隔离退出、重新登录与旧续期。旧请求不能覆盖新令牌、恢复旧用户或清空新会话。
- 网络故障、业务失败和会话失效分别处理，不能把所有异常都解释为需要重新登录。
- Blob / ArrayBuffer 响应先按 Content-Type 识别 JSON 业务错误，再决定下载或续期；正常文件保持原始字节与响应头。
- OIDC 是外部登录方式，本地使用 JWT 或 Redis Token 是会话存储策略。登录完成后仍走同一套本地会话和退出逻辑。

## WebSocket

项目使用 WebSocket，不恢复旧 SSE 或 STOMP 路径：

```text
src/api/realtime/index.ts       HTTP 领票与校准接口
src/utils/realtime/client.ts   建连、心跳、重连和清理
src/utils/realtime/protocol.ts 类型与运行时解析
src/composables/useRealtime.ts 业务订阅与应用生命周期
```

- 复用应用级连接，不在每个组件各开一个 Socket。HTTP 申请短期票据，再用票据握手；不要把长期令牌拼到 URL。
- 主题随领票请求提交，收到服务端 ready 后进入业务可用状态。所有消息先校验，再按类型分发。
- 保持一个有效连接尝试和一个重连任务，迟到回调按尝试身份失效；清理不能再次触发恢复链。
- 重连采用有上限的退避和随机延迟；协议、权限拒绝不能无限重试。凭证到期由服务端校验并关闭连接。
- 重连后通过 HTTP 校准通知、字典或在线统计，不能假定断线期间事件完整重放。权限变化、退出与卸载同步清理订阅。

浏览器实现不直接复制到 uni-app：移动端使用 `UniApp.SocketTask`，并处理应用前后台生命周期。两端保持消息契约一致，传输适配保留平台差异；不要为模板预先设计完整跨平台库。

## 验证

会话检查并发 401、续期失败、退出后旧请求返回、换账号和下载错误；连接检查重复启动、弱网重连、超时、迟到消息及退出清理。复用已有行为测试，新增测试覆盖实际状态变化，不只匹配注释或文件名。
